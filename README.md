# School Days Title Card Generator

I really liked the visual novel/anime *School Days*, and I wanted a title card generator for my *School Days* video to use as video slates / title cards.

## Features
- **Pristine Title Card Style**: Solid deep navy blue background (`#002d62`) and elegant centered typography.
- **Japanese Subtitle & English Synopsis Quote**: Replicates the exact layout of the official title cards.
- **Adjustable Parameters**: Edit text lines, font size, letter spacing, background color, and quote font size in real time.
- **Retro VHS Effect (Optional)**: Toggleable old-school analog tape scanline and static tracking noise filter.
- **Windows 95 Aesthetics**: Nostalgic desktop environment interface complete with a pixelated Win95 pointer cursor.
- **High-Resolution PNG Download**: Export 1920x400 PNG images instantly for video editors and creators.

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
